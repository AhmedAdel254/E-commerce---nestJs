# E-commerce Backend API (NestJS)

A scalable E-commerce Backend API built with NestJS, MongoDB, and Stripe.
The project follows clean architecture principles and includes secure payment processing.

## Features
- User Authentication & Authorization (JWT)
- Products & Categories Management
- Cart Management
- Order Management
- Stripe Payment Gateway Integration
- Search, Filtering & Pagination
- Role-based access control (Admin / User)
- Modular & Scalable Architecture
- Centralized Error Handling

## Tech Stack
- NestJS
- TypeScript
- MongoDB
- Mongoose
- Stripe
- JWT
- bcrypt
- Postman

## Payment Integration
The project uses **Stripe** for handling payments.
Payment flow includes:
- Creating payment intents
- Secure checkout process
- Payment confirmation
- Order creation after successful payment

This simulates a real-world e-commerce payment workflow.

## Project Architecture
The project follows NestJS best practices:
- Modules
- Controllers
- Services
- DTOs
- Guards & Interceptors
